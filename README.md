# Roomii&Co - Customized Textile & Uniform Solutions

## Description
Roomii&Co is a professional website for a B2B textile and uniform solutions provider. The site showcases customized products including uniforms, beddings, towels, blankets, sweatshirts & hoodies, and denim apparel, designed for comfort, durability, and branding.

## Features
- **Responsive Design**: Mobile and laptop friendly with Bootstrap framework
- **Hero Slider**: Interactive swiper showcasing key services
- **Product Offerings**: Detailed cards for each product category
- **Contact Information**: Easy access to contact details
- **Elegant Color Palette**: Soft, muted colors for a professional look

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5.3.3
- Swiper.js for carousel functionality
- Custom JavaScript

## Setup and Installation
1. Clone or download the repository
2. Open `index.html` in your web browser
3. No additional setup required - all dependencies are CDN-based

## File Structure
```

├── css/
```

## Usage
Navigate through the site using the navbar. The hero section features a rotating carousel highlighting different aspects of the business. Scroll down to explore product offerings and contact information.
